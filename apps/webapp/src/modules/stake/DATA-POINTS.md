# Stake module — data-point inventory

Every displayed value in the stake module, per surface and state, traced to its ground truth:
the exact contract read, indexer entity, or price API feeding it; the transform and units on the
way; the formatter; and the refresh semantics. Rows marked **AUD-n** reference the
[findings register](#findings-register) at the bottom. Everything else is verified by code trace,
and the [verification log](#live-verification-log) records which figures were additionally
reconciled wei-exact against a live fork.

Shared components (`ProductTransactionsTable` cells, `TokenIcon`, the shadcn `Slider`) are audited
**as used by stake** — the values stake feeds them and what renders; other modules' usage is out of
scope.

## Source taxonomy

Every value traces to one of these sources. USD conversions name their price source explicitly —
mixing them up is the highest-impact bug class this module has had.

| Code    | Source                       | Details                                                                                                                                                                                                                                                                                                             |
| ------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **MKT** | BA Labs market price API     | `usePrices()` → `GET {BA_LABS}/prices/`, decimal-string per symbol, query key `['prices', chainId]`. Off-chain, trust level 2. Missing base URL resolves `{}` silently; missing symbol reads as `undefined`.                                                                                                        |
| **OSM** | On-chain delayed (OSM) price | `vault.delayedPrice` = `math.delayedPrice(par, spot, mat)` — derived from `MCD_SPOT.par()`, `MCD_VAT.ilks(ilk).spot`, `MCD_SPOT.ilks(ilk).mat` (all RAY → WAD, half-up). Not a direct OSM peek; inverts the vat safety margin. This is what `vat` actually enforces.                                                |
| **PAR** | USDS at 1:1 parity           | No price feed at all — module-wide convention, same as the Savings tables.                                                                                                                                                                                                                                          |
| **BAA** | BA Labs analytics API        | Precomputed fields (`tvl`, `borrow_rate`, `apr`, `number_of_urns`) from `/lsev2/historic/` and `/farms/{addr}/historic/`. Opaque upstream — the webapp does no price math on these. Not available on forks.                                                                                                         |
| **VAT** | Live vault reads             | `MCD_VAT.urns(ilk, urn)` (`ink`, `art`), `MCD_VAT.ilks(ilk)` (`Art`, `rate`, `spot`, `line`, `dust`), via `useVault` / `useCollateralData` / `useStakeTotalDebt`.                                                                                                                                                   |
| **JUG** | Stability fee                | `MCD_JUG.ilks(ilk).duty` (RAY per-second factor). Annualized as `duty^SECONDS_PER_YEAR − 1` (`math.annualStabilityFee`) — compounding, not simple multiplication. `useCollateralData` also simulates `jug.drip(ilk)` for a live `rate` (query `['simulateDrip', ilkHex, chainId]`).                                 |
| **ENG** | LockstakeEngine reads        | `StakeModule.ownerUrns` / `urnFarms` / `urnVoteDelegates`, farm `earned(urn)` / `rewardsToken()` / ERC-20 `symbol()`.                                                                                                                                                                                               |
| **SG**  | Indexer (subgraph)           | `StakingUrn` (positions: `index`, `skyLocked`, `usdsDebt`, `barks[]`, latest mutation timestamps) and per-event entities (`StakingOpen/Lock/Free/Draw/Wipe/GetReward/SelectVoteDelegate/SelectRewardContract/OnKick`) via `useStakeUserPositions` / `useStakeHistory`. No price fields exist at event time (AUD-8). |

### Derived vault fields (`calculateVaultInfo.ts`)

| Field                                | Formula                                                                                                                                                                                                                                                                         | Price source                                      |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `debtValue`                          | `art × rate` (half-up RAY→WAD)                                                                                                                                                                                                                                                  | —                                                 |
| `delayedPrice`                       | `par × spot × mat` (half-up RAY→WAD)                                                                                                                                                                                                                                            | OSM                                               |
| `liquidationPrice`                   | `debtValue × mat / ink`                                                                                                                                                                                                                                                         | — (a derived level, no feed)                      |
| `collateralValue`                    | `ink × delayedPrice`                                                                                                                                                                                                                                                            | OSM                                               |
| `collateralValueNoCap`               | `ink × (marketPrice ‖ delayedPrice)`                                                                                                                                                                                                                                            | MKT, OSM fallback                                 |
| `liquidationProximityPercentage`     | `0` if no debt; **`100` if `liquidationPrice ≥ delayedPrice`** (the OSM guard — evaluated first, so a recovered market price can never mask on-chain liquidatability); `100` if `liquidationPrice ≥ marketPrice`; else `100 − (marketPrice − liquidationPrice)×100/marketPrice` | Hybrid: MKT day-to-day, OSM-gated at the boundary |
| `riskLevel`                          | Tier of proximity: **LOW < 25 ≤ MEDIUM < 40 ≤ HIGH < 80 ≤ LIQUIDATION** (`RISK_LEVEL_THRESHOLDS`)                                                                                                                                                                               | inherits proximity                                |
| `maxSafeBorrowableAmount` / `…NoCap` | `daiAvailable(collateralValue, debt, mat)` — capped variant OSM, NoCap variant MKT                                                                                                                                                                                              | OSM / MKT (AUD-2)                                 |
| `dust`                               | `vat.ilks.dust` RAD→WAD, floored to 1 wei if it rounds to 0                                                                                                                                                                                                                     | —                                                 |

### Formatters

| Fn                        | Behavior                                                                                                                                                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `formatBigInt`            | WAD default. Decimals by magnitude: `<10` → 4, `<1000` → 2, `≥1000` → 0 (2 if compact). Rounds half-expand via `Intl.NumberFormat`. Values `< maxDecimals-step/2` render `<0.0001`-style. Sub-cent prices survive: `0.0025 WAD → "0.0025"`. |
| `formatUsd`               | Always exactly 2 decimals, `$`-prefixed, sign before `$`. **No sub-cent indicator** — genuine dust renders `$0.00` (contrast `formatBigInt`).                                                                                               |
| `formatPercent`           | WAD-scaled ratio in, `Intl` percent out (×100). 2 decimals under 100%, 0 above.                                                                                                                                                             |
| `formatDecimalPercentage` | Plain float: `(value × 100).toFixed(2) + '%'`.                                                                                                                                                                                              |
| `formatStakeAmount`       | `0n → "0.00"` (hi-fi spec), else `formatBigInt` defaults.                                                                                                                                                                                   |
| `formatLiquidatedOn`      | `Intl.DateTimeFormat` en-US, UTC-locked + literal ` UTC` — a bark is a blockchain fact, not viewer-local.                                                                                                                                   |

### Refresh semantics

The four transaction success handlers (`OpenPositionTakeover`, `ManagePositionTakeover`,
`StakeClaimModal`, `LiquidationPostMortemModal`) invalidate the same key set:
`['stake-user-positions']`, `['stake-history']`, `['readContract']`, `['readContracts']`,
`['simulateDrip']`. The last two were added by this audit — wagmi's batched `useReadContracts`
keys under `['readContracts', …]` (plural), a **different top-level key** from the singular
`['readContract', …]`, so claimable rewards, wallet balances, and the live total-debt aggregate
were previously never refreshed by any stake transaction; `['simulateDrip']` feeds the live `rate`
leg of `useCollateralData`'s debt math and was never invalidated anywhere.

Price/analytics feeds (`['prices']`, `['stake-historic-data']`, `['reward-charts']`,
`['stakeRewardContracts']`) are deliberately not tied to tx success — they are market data, not
urn state.

Key inventory (✅ = invalidated by all four success handlers):

| Key                                                                                         | Hook                                                                                                                      | Post-tx                               |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| `['stake-user-positions', …]`                                                               | `useStakeUserPositions`                                                                                                   | ✅                                    |
| `['stake-history', …]`                                                                      | `useStakeHistory`                                                                                                         | ✅                                    |
| `['readContract', …]`                                                                       | every singular `useReadContract` (vault, urn selections, allowances)                                                      | ✅                                    |
| `['readContracts', …]`                                                                      | `useRewardContractsToClaim`, `useStakeTotalDebt`, `useAllStakeUrnAddresses`, `useTokenBalance`, `useRewardContractTokens` | ✅ (this audit)                       |
| `['simulateDrip', …]`                                                                       | `useCollateralData`'s drip simulation                                                                                     | ✅ (this audit)                       |
| `['prices', chainId]`                                                                       | `usePrices`                                                                                                               | — (market feed)                       |
| `['stake-historic-data', chainId]` / `['reward-charts', …]` / `['stakeRewardContracts', …]` | analytics                                                                                                                 | —                                     |
| `['stake-position-details', …]` / `['user-total-staked', …]`                                | `useStakePosition` / `useTotalUserStaked`                                                                                 | dead code / unused in module (AUD-17) |

## Open takeover (`OpenPositionTakeover` + cards)

Same sourcing as Manage except: 25/50% chips do **not** floor to whole SKY (**AUD-10**); the
"Protocol SKY Price" stat renders ungated while its sibling liquidation-price stat waits for an
amount (**AUD-12**); the confirm summary shows **no USD subvalue at all** (**AUD-3**, contrast
Manage). Reopen mode swaps the launch to the manage flow and prefers the urn's existing
farm/delegate; the delegate baseline deliberately splits raw vs zero-filtered reads to avoid a
spurious `selectVoteDelegate(0x0)`.
